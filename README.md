# AllyMailer agent skills

Skills for AI coding agents (Claude Code, Cursor, Codex, Copilot, Gemini CLI, …) in the
[Agent Skills](https://agentskills.io) format: integrate the AllyMailer transactional email Web API, write email templates,
get to the inbox and migrate from other providers.

## Install

```bash
npx skills add allymailer/allymailer-skills
```

Claude Code plugin: `/plugin marketplace add allymailer/allymailer-skills`, then `/plugin install allymailer@allymailer-skills`.

## Skills

| Skill | For |
|---|---|
| [`allymailer`](skills/allymailer/SKILL.md) | The AllyMailer Web API: sending, templates, webhooks, domains, sandbox, SDKs |
| [`allymailer-email-templates`](skills/allymailer-email-templates/SKILL.md) | HTML emails for mail clients, template engines, the visual editor |
| [`allymailer-email-best-practices`](skills/allymailer-email-best-practices/SKILL.md) | Deliverability, compliance, list hygiene, reliability |
| [`allymailer-migrate`](skills/allymailer-migrate/SKILL.md) | Move from SendGrid, Mailgun, Resend, Postmark |

## Prerequisites

- A AllyMailer account: https://cp.allymailer.com
- An API key in `ALLYMAILER_API_KEY`

## Generated

The skills are generated by the AllyMailer team from the AllyMailer Web API spec, like the SDKs: do not edit this repository by
hand, the next release replaces it. Report problems in the issues of https://github.com/allymailer/allymailer-skills.
